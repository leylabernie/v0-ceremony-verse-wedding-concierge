# Self-hosted fonts

Latin variable WOFF2 assets from Fontsource npm packages, version 5.3.0:
- `@fontsource-variable/cormorant-garamond`: normal and italic, weights 300–700.
- `@fontsource-variable/dm-sans`: normal, weights 100–1000.

Both families use the SIL Open Font License 1.1; their licenses are included here.
Loaded with `next/font/local` to preserve existing CSS variables and eliminate
build-time requests to Google Fonts. No font dependency install is required.
